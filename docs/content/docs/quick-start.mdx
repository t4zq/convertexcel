## 1. 表をコピーする

Excelまたはスプレッドシートで必要な範囲を選択し、コピーします。見出しを含めてコピーすると、そのまま表のヘッダーとして利用できます。

## 2. converTeXcelへ貼り付ける

[変換画面](https://convertexcel.net/convert)の入力欄へ貼り付けます。タブ区切りのデータとして読み込まれ、表形式で確認できます。

## 3. 出力形式を選択する

用途に応じてLaTeX表、CSV、TikZ/PGFPlots、gnuplotを選択します。

## 4. プレビューしてコピーする

有効数字、列の配置、単位などを調整し、PDFプレビューで確認します。完成したコードはコピーボタンからレポートへ貼り付けられます。
