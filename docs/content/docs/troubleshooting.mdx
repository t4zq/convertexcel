## 表が正しく分割されない

Excelからコピーしたデータはタブ区切りであることを確認してください。Webページ上の表は、いったんExcelへ貼り付けてからコピーすると安定します。

## LaTeXで`Undefined control sequence`が表示される

生成コードが利用するパッケージをプリアンブルへ追加します。

```latex
\\usepackage{booktabs}
\\usepackage{siunitx}
\\usepackage{pgfplots}
```

## `&`や`%`でコンパイルに失敗する

LaTeXで特別な意味を持つ文字は、文字として使用する場合にエスケープが必要です。

| 入力 | LaTeX |
| --- | --- |
| `A & B` | `A \\& B` |
| `50%` | `50\\%` |

<Callout type="warn" title="解決しない場合">
PDFプレビューに表示されるログと、再現できる最小限の入力データを添えて報告してください。個人情報や未公開データは含めないでください。
</Callout>
