converTeXcelは、Excelやスプレッドシートの表をレポートで使えるコードへ変換するWebアプリです。変換処理はRust/WebAssemblyにより、基本的にブラウザ内で行われます。

## 対応する出力

- LaTeX表（`booktabs`、`siunitx`対応）
- TikZ / PGFPlotsコード
- gnuplotスクリプトとブラウザ内プレビュー
- CSV

<Callout title="データの扱い">
入力データの変換とコード生成は基本的にブラウザ内で実行されます。PDFプレビューを使用した場合のみ、生成したTeXコードがコンパイルサービスへ送信されます。
</Callout>
