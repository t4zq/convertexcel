## 出力形式を選ぶ

LaTeX文書へ直接組み込む場合はTikZ/PGFPlots、手軽にグラフを確認・出力する場合はgnuplotが向いています。

<Tabs items={["TikZ / PGFPlots", "gnuplot"]}>
  <Tab value="TikZ / PGFPlots">
    レポート本文と同じフォント・数式表現でグラフを組版できます。
  </Tab>
  <Tab value="gnuplot">
    ブラウザ内で素早くプレビューし、スクリプトとして保存できます。
  </Tab>
</Tabs>

## 軸と系列

1列目を$x$軸、2列目以降を系列として選択できます。非連続列はExcelアドインからも読み込めます。

```latex
\\begin{axis}[
  xlabel={Time / \\si{\\second}},
  ylabel={Voltage / \\si{\\volt}},
  grid=major,
]
  \\addplot table [x=time, y=voltage, col sep=comma] {data.csv};
\\end{axis}
```

<PackageList>
TikZグラフには`pgfplots`、単位には`siunitx`を使用します。
</PackageList>
